Privacy Architecture

Built for one constraint: nothing leaves the device

This was not a feature added later. It is the founding constraint. Every technical decision flows from it.

SHA-256 PIN Vault

The vault PIN is stored as a SHA-256 hash — never in plaintext. Access requires the correct PIN on every session. No "forgot PIN" flow exists because there is no server to reset it against.

AsyncStorage — Local Only

All data is persisted via AsyncStorage on-device. No sync engine. No background upload. No CDN. The data exists exactly where you wrote it and nowhere else.

Zero Network Permissions

The app requests no network permissions. It cannot make outbound connections. There is no analytics SDK, no crash reporter, no ad framework. Verified in the manifest.

Features

A real relationship manager — not a contacts list

Trust scoring, health engine, reminders, voice notes, meeting prep. Everything a CRM has, minus the server bill and the data leak.

Trust Scoring 0-10

Each contact has a colour-coded trust level — 0-10, rendered red/yellow/green. Not a star rating. A deliberate assessment of the relationship.

Relationship Health Engine

An auto-calculated health score surfaces which relationships are thriving and which are going cold — based on interaction frequency, sentiment notes, and milestones.

Rich Notes

Per-contact notes include likes, dislikes, quick facts, and a free-form description. Voice interaction notes capture what was said in a conversation, with timestamps.

Local Reminders

Birthdays, meetings, and follow-ups trigger local device notifications — not server push. The reminder engine runs entirely offline.

Colour-Coded Groups

Contacts are organised into custom colour-coded groups. Meeting prep cards surface key facts about a contact before you see them — names remembered, context loaded.

Android and iOS

Built with React Native and Expo SDK 54. Runs natively on both Android and iOS from a single codebase. Expo Router handles navigation.
